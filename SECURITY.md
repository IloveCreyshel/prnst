## Reporting a Vulnerability

If you discover a security vulnerability within this prototype project, please report it responsibly. 

* **Do not** open public GitHub issues for security vulnerabilities.
* Instead, please report them by reaching out directly via GitHub profile discussions or sending a private message/email to the repository maintainer.

Please include the following details in your report:
* Description of the vulnerability and steps to reproduce.
* Potential impact of the issue.
* Any possible mitigations you have already identified.

You can expect an initial response within 48–72 hours acknowledging receipt of your report. Thank you for helping keep this project secure!
